# Checklista wydania

- [ ] wszystkie zmiany z wersji produkcyjnej są w repozytorium
- [ ] numer `versionCode` został zwiększony
- [ ] numer `versionName` jest poprawny
- [ ] build GitHub Actions jest zielony
- [ ] aplikacja uruchamia się na Androidzie 10/11
- [ ] planer, odjazdy i synchronizacja działają
- [ ] powiadomienia działają
- [ ] odpady działają
- [ ] pogoda i Karta dnia działają
- [ ] brak kluczy, haseł i sekretów w repozytorium
- [ ] APK release jest podpisany właściwym stałym kluczem
- [ ] utworzono tag `vX.Y.Z` i GitHub Release
