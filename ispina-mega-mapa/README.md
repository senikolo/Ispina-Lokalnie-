# Mega lokalna mapa Ispiny

Produkcja: https://ispina-mega-mapa-senikolo.vercel.app/

Statyczna strona HTML, bez kroku kompilacji i bez wymagania konta ChatGPT dla odbiorców. Zachowuje zewnętrzne źródła danych GUGiK, mapy i monogram IL.

Źródło migracji: aktualna wersja 11 projektu Sites appgprj_6ae03757427c8191bf1df539e65ada5d, commit 16d77001aeb57c7da672ec5998230b3614631732. Wdrożenie na istniejącym projekcie Vercel ispina-mega-mapa w zespole senikolo. Plik index.html jest identyczny z migrowanym źródłem.

Publikacja na Vercelu obejmuje index.html i vercel.json. Projekt jest statyczny, framework=null; brak instalacji zależności i kompilacji. Przy kolejnych zmianach należy aktualizować tę kopię i istniejący projekt Vercel, a linki WordPress pozostawiać skierowane na powyższy adres produkcyjny.
