# Źródła danych i atrybucja

| Funkcja | Źródło | Sposób użycia |
|---|---|---|
| Rozkłady MLD | [Koleje Małopolskie — rozkłady autobusowe](https://kolejemalopolskie.com.pl/pl/rozklad-jazdy/rozklady-autobusowe), [publiczny feed GTFS](https://kolejemalopolskie.com.pl/rozklady_jazdy/ald-gtfs.zip) | Aplikacja pobiera feed po wybraniu przycisku „Pobierz MLD”, przetwarza go lokalnie i zapisuje na urządzeniu. |
| Linia gminna | [Gmina Drwinia — komunikacja w 2026 r.](https://www.drwinia.pl/aktualnosci/funkcjonowanie-linii-komunikacyjnych-na-terenie-gminy-drwinia-w-roku-2026,news-3151) | Dołączona tabela jest roboczym opracowaniem; czasy pośrednie są oznaczone jako szacunkowe. Przed użyciem należy sprawdzić aktualny rozkład gminy. |
| Odpady | [Gmina Drwinia — harmonogram odbioru odpadów 2026](https://www.drwinia.pl/aktualnosci/harmonogram-odbioru-odpadow-z-terenu-gminy-drwinia-2026-rok,news-3175) | Daty dla obszaru Grobla, Ispina, Trawniki zapisano jako dane aplikacji z podaniem źródła i daty ważności. |
| Aktualności i historia | [Ispina Lokalnie](https://ispinalokalnie.wordpress.com/) — publiczny WordPress REST API | Aplikacja pobiera treść jako dane, usuwa niebezpieczne elementy HTML i nie wykonuje skryptów z odpowiedzi. |
| Pogoda i słońce | [Open-Meteo](https://open-meteo.com/) | Prognoza dla współrzędnych Ispiny. Dane Open-Meteo są udostępniane na licencji Creative Commons Attribution 4.0 International (CC BY 4.0); aplikacja podaje dostawcę i link do źródła w ekranie pogody i informacji o aplikacji. |
| Radio i TV | Oficjalne strony [Jedynki](https://jedynka.polskieradio.pl/), [ESKI](https://player.eska.pl/), [RMF FM](https://www.rmf.fm/radio.html), [TVP3 Kraków](https://krakow.tvp.pl/) | Aplikacja otwiera player nadawcy; nie zawiera strumieni ani odtwarzania w tle. |

Znaki Kolei Małopolskich, Gminy Drwinia, Open-Meteo, WordPress, Polskiego Radia, ESKI, RMF i TVP należą do ich właścicieli. Lista źródeł nie oznacza ich poparcia dla aplikacji.
